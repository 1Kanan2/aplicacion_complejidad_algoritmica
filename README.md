# Aplicación desarrollada para el curso de Complejidad Algorítmica
 
El presente trabajo tiene como objetivo optimizar el proceso de referencia médica en el Perú mediante el uso de algoritmos de grafos. La propuesta consiste en modelar la red de establecimientos de salud como un grafo dirigido y ponderado, donde los nodos representan centros de salud de distintos niveles de complejidad y las aristas reflejan las rutas de referencia entre ellos, asignando como peso la distancia geodésica (en kilómetros) entre los establecimientos.

Se emplearán algoritmos de optimización de rutas y análisis de redes para mejorar la eficiencia del Sistema de Referencia y Contrarreferencia (SRC) del Ministerio de Salud (MINSA), reduciendo los tiempos de traslado de pacientes y garantizando la atención oportuna en los niveles de mayor complejidad.
El objetivo principal es desarrollar un sistema que determine las rutas óptimas de referencia médica entre establecimientos de salud del Perú, específicamente para el traslado de pacientes desde centros de primer nivel (IPRESS I) hacia hospitales de mayor complejidad (IPRESS II o III).
